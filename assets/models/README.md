# Shipped 3D models

Runtime payloads under this folder (Meshy heroes, punk dog, `meshy/shipped.json`) are used by the living-3D slice.

| Path | Source | License |
|------|--------|---------|
| `meshy/punk_pink.glb` | [Meshy](https://meshy.ai) — Neon Rebel | CC BY 4.0 (see `meshy/LICENSE.txt`) |
| `meshy/mohawk.glb` | Meshy | CC BY 4.0 |
| `meshy/cobalt.glb` | Meshy | CC BY 4.0 |
| `meshy/razor.glb` | Meshy | CC BY 4.0 |
| `pets/punk_dog.glb` | Meshy-derived pet mesh | CC BY 4.0 |

Animations and material styling are applied in code (`js/world/meshy-punk.mjs`, `js/world3d.mjs`).

Removed CC0 demo meshes (`character.glb`, `punk-teen.glb`, etc.) are not shipped in this branch.
