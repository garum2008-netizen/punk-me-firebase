# PUNK ME — дорожная карта

## Текущее состояние (после этого релиза)

**PUNK ME** — оригинальная браузерная мультиплеерная игра про подростковую панк-банду в неоновую хэллоуин-ночь. Стек: статический хостинг (GitHub Pages), Firebase Anonymous Auth + Realtime Database.

### Уже работает

- **Локации:** комната, кухня, туалет, лифт, крыша, улица банды, кладбище у Вены, город (стройка), крышный паркур — переходы через двери/лифт.
- **Прогресс:** монеты, XP, уровень, репутация, сохранение по анонимному `uid`.
- **Мультиплеер:** присутствие игроков в одной локации (`presence/{location}`), общий чат.
- **Лавка:** одежда, цепи, панк-магия (свитки), звери ночи (кот/крыса/ворона), материалы для стройки.
- **NPC банды:** диалоги, квесты, вызов на цепную дуэль.
- **Работа:** кладбище — копать / убирать / поливать с кулдауном и оплатой.
- **Драки:** пошаговая цепная дуэль с NPC (цепь, пинок, свитки).
- **Магия:** заклинания в мире и в бою.
- **Стройка:** размещение склепов/домов/неона в городе (общая база `buildings/city`).
- **Ночь:** коты, полиция, мусор, огни (интерактив на ночных локациях).
- **Арт:** фоны и портреты из `imagine_images/`.

### Хостинг и Firebase

- Сайт: `halloween.punk.contractbot.dk` — GitHub Pages, ветка `main`, корень репозитория (`CNAME`).
- Правила RTDB: `database.rules.json` (игрок — только свой узел, presence/chat/buildings по схеме).

## Пробелы и риски

| Область | Статус |
|--------|--------|
| PvP между игроками | Только NPC; нужен синхронный `fights/` и матчмейкинг |
| Античит экономики | Награды в основном на клиенте — нужна серверная валидация (Functions) |
| Правила RTDB в проде | Нужен `firebase deploy --only database` после мержа |
| Модульность кода | Один `game.js` — позже разбить на модули + сборщик |
| Звук и анимации | Минимум; можно добавить Web Audio и спрайты |
| Мобильное UX | Есть адаптив, но управление лучше джойстиком |

## Фазы развития (кратко)

1. **Ядро (сделано)** — локации, сохранение, presence, экономика, квесты.
2. **Социал и PvP** — вызов игрока на дуэль, общие события на улице, модерация чата.
3. **Мир** — больше районов, процедурные ночные ивенты, полиция с последствиями.
4. **Стройка 2.0** — личные кварталы, апгрейд склепов, репутация района.
5. **Магия и цепи** — комбо, редкие артефакты, крафт из материалов.
6. **NPC** — ветвящиеся диалоги, ежедневные контракты банды.
7. **Инфра** — Cloud Functions для наград, CI preview, e2e-тесты Playwright.

**Рекомендуемый следующий шаг:** фаза 2 (PvP между игроками + серверная проверка наград), чтобы мультиплеер ощущался честным и живым.
