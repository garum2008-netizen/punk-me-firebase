# PUNK ME — требования UI/UX

Языки: **RU / EN / DA**. Возрастная метка **13+** в подвале и на `subscribe.html`.

---

## HUD (в игре)

| Элемент | Требование | Статус v22r3 |
|---------|------------|--------------|
| Монеты, XP, уровень | Всегда видны | IMPLEMENTED |
| Репутация | Число или уровень | IMPLEMENTED |
| Авторитет | Полоска + ранг | IMPLEMENTED (`authority.mjs`) |
| Версия сборки | `#gameVersion` | IMPLEMENTED |
| Переключатель языка | RU / EN / DA | IMPLEMENTED |
| Голос mute | Кнопка в HUD / how-to mobile | IMPLEMENTED |
| Чат банды | Не перекрывает джойстик на mobile | IMPLEMENTED (QA `mobile-hud-layout.png`) |

**TBD — needs owner input:** единый стиль иконок энергии/настроения (ТЗ §1.2).

---

## Панель квестов (Quest log)

- Контейнер `#questBox`.  
- Онбординг: компактный трекер шагов.  
- После онбординга: активный квест Story Engine + прогресс шага.  
- Mobile: сворачиваемый список, высота верхнего HUD ≤20% экрана (QA v22r3).

---

## Карта

**PLANNED** (ТЗ подразумевает ориентиры через **маяки**, не полноэкранную карту).

| Функция | Альтернатива в v22 |
|---------|-------------------|
| Мини-карта района | Маяк + портальные подписи |
| Метки квестов | `!` над NPC, `storyDirection` |

**TBD — needs owner input:** нужна ли отдельная карта Тыквограда в v24+.

## Инвентарь

- Одежда / цепи: через **лавку** и гардероб в комнате.  
- Материалы стройки: строка «Нужно: …» в UI стройки (ТЗ).  
- Отдельный рюкзак-слот — **PLANNED**.

---

## Подсказки и маяки

| Тип | Поведение |
|-----|-----------|
| Маяк на земле / NPC | `World3D.setGuideTarget` |
| «E — говорить» | Подсказка при proximity |
| Нехватка монет | Неактивная «Купить» + текст ТЗ §1.5 |
| Индикатор NPC за кадром | ТЗ §3 — **PLANNED** |

---

## Диалоги

- `#storyDialog`: портрет, текст, кнопки выбора.  
- Framing камеры: `engageDialogueFraming` (v22 — без пересвета на mobile).  
- Субтитры: `#voiceSubtitle` под диалогом/HUD.

---

## Нижняя панель действий

Кнопки: банда, лавка, магия, работа, стройка, драка, паркур — контекстно по локации (`job_go_cemetery`, `job_go_city`).
