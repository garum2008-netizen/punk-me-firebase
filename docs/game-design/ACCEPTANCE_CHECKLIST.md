## Запуск и интро

- [ ] Сайт открывается: [halloween.punk.contractbot.dk](https://halloween.punk.contractbot.dk)
- [ ] Выбор героя и вход в мир без ошибок в консоли
- [ ] Кинематографическое интро ~85 с воспроизводится (или осознанно пропущено в релизе) — **PLANNED**
- [ ] Быстрое интро 20 с доступно — **PLANNED**

## Голос и субтитры

- [ ] Дешёкий live TTS **не** используется в сюжете
- [ ] Субтитры RU при русском UI
- [ ] Субтитры EN при английском UI
- [ ] Субтитры DA при датском UI
- [ ] Mute/громкость сохраняются в `localStorage`
- [ ] Pre-rendered клипы (если есть в `assets/audio/voice/`) проигрываются без ошибок

## Управление и обучение

- [ ] Игрок понимает управление после «Как играть» / онбординга
- [ ] WASD / стрелки — ходьба (desktop)
- [ ] Shift — бег (desktop)
- [ ] Пробел — прыжок
- [ ] E — взаимодействие / диалог
- [ ] Камера: ПКМ+мышь / свайп (mobile)
- [ ] Mobile: джойстик + кнопка E
- [ ] Первый квест/онбординг активен сразу после входа
- [ ] NPC выдают задания (диалог + accept)
- [ ] Маяки / «!» показывают путь к цели

## Геймплей и прогресс

- [ ] Монеты начисляются за работу/квесты
- [ ] Прогресс сохраняется после перезагрузки (Firebase uid)
