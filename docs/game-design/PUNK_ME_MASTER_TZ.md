**Продукт:** PUNK ME · **Владелец:** Inna Kragh · **Аудитория:** 13+ (без крови, жестокости, скримеров; тон — панк-юмор)

## 1. Концепция и цель

**PUNK ME** — оригинальная браузерная 3D multiplayer life-sim: подростковая панк-банда «**Ржавые Цепи**» в вечном хэллоуин-городе **Тыквоград**. Игрок — новичок в доме №13; цель — завоевать **Авторитет**, вступить в банду, построить **Тусовку**, раскрыть тайну **Колокола замка** и выбрать одну из трёх «хороших» концовок.

**Задача дизайна (из ТЗ):** в каждый момент игроку понятно следующее действие; локации живые (NPC, задания); выбор меняет репутацию и ветки; нехватка монет ведёт к работе с подсказкой и маяком.

---

## 2. Игровой цикл (core loop)

```
NPC окликает → задание (панель цели + маяк + «!») → выполнение (иногда выбор)
  → награда (монеты / XP / репутация / материалы) → траты (стройка, одежда, питомец)
  → новая локация или квест
Нет монет → подцель «Заработай N» → работа (2–4 мин) → возврат к цели
```

См. [GAME_ECONOMY.md](./GAME_ECONOMY.md), [QUESTS_AND_GAMEPLAY.md](./QUESTS_AND_GAMEPLAY.md).

## 4. Путь новичка к Авторитету (параллельная дуга)

Ранги (шкала 0–100): **Новенький** → **Под присмотром** → **Испытуемый** → **Свой** → **Член банды**.

1. **Насмешки** — выбор реакции (отшутиться / уйти / огрызнуться / сбежать).  
2. **Проверки** — поручения (пицца для банды, флаеры и др. по `authority-path.json`).  
3. **Испытания** — дуэль цепями, граффити и т.д.  
4. **Посвящение** — нашивка, флаг `joined_gang`.

После вступления — сюжетный выбор **анти-буллинга** (заступиться за новенького или присоединиться к насмешкам).

## 6. Управление и камера

**Desktop:** WASD / стрелки — ходьба; **Shift** — бег; **Пробел** — прыжок; **E** — разговор/действие; ПКМ + мышь — камера; клик по полу — идти.

**Mobile:** джойстик слева (дальше от центра = бег); кнопка **E** справа; свайп справа — камера.

Детали верификации шагов: [INTERACTIVE_TUTORIAL.md](./INTERACTIVE_TUTORIAL.md).

## 7. UI

- HUD: монеты, XP, уровень, репутация, полоска **Авторитет**, версия.  
- Панель квестов (`#questBox`), диалог (`#storyDialog`), субтитры (`#voiceSubtitle`).  
- Нижняя панель: банда, лавка, магия, работа, стройка, драка, паркур.

Требования: [UI_UX_REQUIREMENTS.md](./UI_UX_REQUIREMENTS.md).

## 8. Прогрессия и сохранения

- Стартовые монеты: **100** (ТЗ §1.6).  
- XP на уровень: **100 × уровень** (кумулятивно по ТЗ).  
- Репутация: уровни «Никто» / «Свой» / «Панк» / «Легенда района».  
- Отношения: банда «Ржавые Цепи», семья Мёртвиновых, Граф (глава 4).  
- Сохранение: Firebase RTDB по анонимному `uid` (`window.me`, ветка `story` для сюжета).
