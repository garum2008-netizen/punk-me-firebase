# PUNK ME — озвучка и субтитры

## Принципы (ТЗ §0.5)

1. **Базовый уровень для всех реплик:** текстовый пузырь над NPC + **субтитры** внизу + короткий невербальный звук (свист, «Эй!», звон цепи).  
2. **Полная озвучка** — только при наличии **качественной** записи (живой актёр / студия).  
3. **Дешёвый рубленый TTS запрещён.** В v22r3 модуль `js/voice.js` **удалил** live `speechSynthesis`.  
4. Если клипа нет — реплика **без голоса**, только пузырь + субтитры + SFX-сигнал.

> Примечание: файл [docs/VOICE.md](../VOICE.md) описывает старую сборку с Web Speech API; для living3d-v22r3 ориентируйтесь на этот документ и `js/voice.js`.

## Языки RU / EN / DA

- UI и субтитры: `js/i18n.js`, ключи диалогов в `data/story/*.json` (объекты `{ ru, en, da }`).  
- `Voice.langKey()` выбирает папку `assets/audio/voice/<ru|en|da>/`.  
- При смене языка в игре субтитры переключаются сразу; очередь озвучки сбрасывается при mute.

---

## Синхронизация субтитров

- Элемент `#voiceSubtitle`; показ через `Voice.showSubtitle(text, characterId)`.  
- Длительность: `max(2200 ms, 45 ms × длина текста)` — до появления pre-rendered клипов с точной длительностью.  
- Имя говорящего: `tNpcName(characterId)` + «: » + текст.

**Целевое улучшение (PLANNED):** привязка к `audio.duration` и таймкодам `.vtt` для длинных сцен.

## Мобильные браузеры

- Воспроизведение `Audio()` после пользовательского жеста (первый тап «Голос вкл»).  
- Без автоплея озвучки при загрузке (mute по умолчанию снимает риск блокировки).  
- Субтитры всегда доступны (читаемость на маленьком экране, контраст в `css/game.css`).

---

## Безопасная интеграция TTS (если когда-либо)

**Не использовать** в продакшене браузерный `speechSynthesis` для сюжета.

Допустимый pipeline (PLANNED):

1. Студийная запись или **batch neural TTS** офлайн → экспорт **OGG/MP3**.  
2. Именование: `assets/audio/voice/<lang>/<characterId>_<hash>.ogg` (как в `Voice.clipUrl`).  
3. Лицензия голоса и актёра — строка в README ассетов.  
4. В игре: только `fetch` + `Audio`; fallback `onerror` → субтитры без звука.
