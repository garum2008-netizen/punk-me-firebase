# PUNK ME — тестовая сборка и план для тестировщиков

Версия документа: **living3d-v22r5** (ветка после merge PR #11 / docs #10).

## Как открыть тестовый режим

| Способ | URL |
|--------|-----|
| Параметр | `https://<хост>/index.html?test=1` (рекомендуется `&solo=1` для одиночной игры без чужих игроков) |
| Короткая ссылка | `/beta.html` → редирект на `index.html?test=1&solo=1` |

Тестовый режим запоминается в `localStorage` (`punkme_test=1`).

## Что видит тестер

- Панель **TEST** с версией сборки (`GAME_VERSION` в HUD и в панели).
- **Bug report** — копирует в буфер: версия, URL, viewport, язык, User-Agent, время.
- **+5000 coins** — тестовые монеты (не реальные платежи).
- **Reset progress** — удаляет запись игрока в Firebase для текущего anonymous UID и перезагружает игру (**осторожно**).
- Быстрые кнопки **локаций** (10 сцен).
- Прыжки сюжета: **Auth stage 1 / 4**, **Chapter 2** (анти-буллинг).
- Кнопки **Поделиться** / **Установить** (PWA) в нижней панели.

## План тестирования (чеклист)

### 1. Старт и онбординг
- [ ] Выбор героя (4 персонажа), вход в комнату.
- [ ] 6 шагов «Новенький» (движение, улица, Razor, кладбище, дуэль, покупка).
- [ ] Панель «Как играть» (?), RU/EN/DA.

### 2. Мир и навигация
- [ ] Все 10 локаций через карту и двери/порталы.
- [ ] Мобильный джойстик, Chat и «Здесь:N» не перекрывают друг друга.

### 3. Сюжет «Авторитет»
- [ ] Этапы 1–4 (мohawk → задания → испытания → посвящение Razor).
- [ ] Глава 2: выбор анти-буллинга, последствия для реплик NPC.

### 4. Экономика
- [ ] Работы: пицца (город), кладбище, кухня (если доступны).
- [ ] Лавка: покупка предмета за монеты.
- [ ] Стройка: режим постройки на construction.

### 5. Бой
- [ ] Цепная дуэль с NPC, HP, победа/поражение.

### 6. Сохранение
- [ ] Перезагрузка страницы — персонаж, локация, монеты, сюжетные флаги.

### 7. PWA
- [ ] Chrome: «Установить приложение» / Safari: «На экран Домой».
- [ ] Офлайн: открыть `offline.html` при потере сети после установки.
- [ ] Поделиться: Web Share или копирование ссылки + QR.

### 8. Монетизация (без оплаты)
- [ ] `subscribe.html` — цена и тексты 13+ / 4,99 € без изменений.
- [ ] Кнопка подписки **disabled**, «оплата не подключена».
- [ ] Ссылки Terms / Privacy открываются.

## Отчёт об ошибке

Нажмите **Bug report** в тест-панели, вставьте текст в письмо/issue и опишите шаги воспроизведения. Приложите скриншот или короткое видео.
