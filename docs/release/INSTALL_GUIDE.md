# PUNK ME — как установить игру (игрокам)

RU / EN / DA · **PWA + браузер** (living3d-v22r5).

---

## RU — macOS (Chrome)

1. Откройте **https://halloween.punk.contractbot.dk** (или тестовый хост).
2. Войдите в игру (выбор персонажа).
3. Меню **⋮** → **«Установить PUNK ME…»** / **Install app**.
4. Иконка появится в Launchpad; можно **Add to Dock**.

## RU — macOS (Safari)

1. Откройте сайт в Safari.
2. **Файл → Добавить в Dock** (или «Add to Dock» в меню «Поделиться»).
3. Запуск как отдельное окно.

## RU — iPhone / iPad

1. Откройте в **Safari** (не встроенный браузер Telegram/Instagram).
2. Кнопка **Поделиться** → **«На экран Домой»**.
3. Подтвердите имя **PUNK ME**.

## RU — Android

1. Откройте в **Chrome**.
2. Меню → **«Установить приложение»** / баннер установки.
3. Или: **Добавить на главный экран**.

## RU — Windows

1. **Chrome** или **Edge** → откройте сайт.
2. Иконка установки в адресной строке → **Установить**.
3. Запуск из меню «Пуск».

## RU — поделиться с другого устройства

В игре кнопка **«Поделиться»**: системный share, копирование ссылки или QR-код.

---

## EN — macOS (Chrome)

1. Open the game URL in Chrome.
2. Menu **⋮** → **Install PUNK ME…**
3. Launch from Applications or Dock.

## EN — iPhone / iPad

1. Open in **Safari**.
2. **Share** → **Add to Home Screen**.

## EN — Android

1. Chrome → **Install app** prompt or menu → Install.

## EN — Windows

Chrome/Edge → install icon in address bar → **Install**.

---

## DA — macOS / iPhone / Android / Windows

1. Åbn spillet i **Chrome** (Mac/Win/Android) eller **Safari** (iPhone).
2. **Installer app** / **Føj til hjemmeskærm** / **Add to Dock**.
3. Brug **Del** i spillet for at sende link til en anden enhed.
