## Сохранение (блокер #1)

1. Новый гость → мало монет → покупка в лавке отклонена → toast, игра продолжается.
2. Заработать монеты (работа/квест) → купить → **«Сохранено»** после успешной записи.
3. F5 → монеты, инвентарь, **этап обучения**, активное задание на месте.
4. При ошибке записи — видимый toast + статус «Ошибка сохранения».

## Управление

- RU раскладка: **E** (физическая), WASD/стрелки двигают; в поле чата — не двигают.
- Кнопки **Сменить героя** / **Без голоса** — не переключают язык.
