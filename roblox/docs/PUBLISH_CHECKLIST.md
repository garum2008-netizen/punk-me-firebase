# Чеклист публикации Roblox (по §13 Roblox-ТЗ)

Не копировать возрастной рейтинг 13+ без прохождения **Maturity questionnaire** по фактическому контенту.

## Владелец и доступ

- [ ] Experience создан под **согласованным аккаунтом или группой Инны** (не личный аккаунт разработчика).
- [ ] Cloud-агенту выдан доступ на редактирование (или владелец сам заливает `.rbxlx`).

## Контент и права

- [ ] Реестр аудио, изображений, моделей (`INVENTORY.md` + обновления).
- [ ] Нет заимствований из чужих Roblox-игр / Avatar World.
- [ ] Иконка и промо-кадры — из **реального** Roblox-плейса, не из браузерной Three.js-версии.

## Техника

- [ ] Приватная версия → тест 2+ игроков, мобильный клиент.
- [ ] Production DataStore без суффикса `_TEST` только после явного решения.
- [ ] Developer Products: реальные ID и цены только после согласования с Инной.
- [ ] ProcessReceipt проверен на дубликаты покупок.

## Maturity / аудитория

- [ ] Опросник по фактам: нет натуралистичного насилия на кладбище; дуэль — учебная, стилизованная.
- [ ] TextChat — только штатная фильтрация Roblox.

## Коммуникация

- [ ] Описание experience на 4 языках (кратко).
- [ ] План отката (предыдущая версия place file).

## Запреты (текущая фаза)

- **Не публиковать** без отдельного разрешения Инны.
- **Не включать** реальные покупки и секреты в репозитории.
